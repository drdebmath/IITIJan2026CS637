Part B: Proof Questions

These questions ask for short proofs of standard facts about Eulerian cycles, Hamiltonian cycles, bridges, and graph distance.
Q11 Even Degrees in Eulerian Graphs

Prove that if a connected graph has an Eulerian cycle, then every vertex of the graph has even degree.

Q12 Odd-Degree Endpoints of an Eulerian Trail

Prove that if a connected graph has an Eulerian trail that is not a cycle, then the graph has exactly two vertices of odd degree.

Q13 Distance Decomposition Along a Shortest Path

Prove that if \(d(u,v)\ge 2\), then there is a vertex \(z\) in \(G\) such that \[ d(u,v)=d(u,z)+d(z,v). \]

Q14 Minimum Degree in a Hamiltonian Graph

Prove that if a graph has a Hamiltonian cycle, then every vertex has degree at least 2.

Q15 Bipartite Hamiltonian Graphs

Prove that if a bipartite graph has a Hamiltonian cycle, then the two parts of the bipartition have the same number of vertices.

Q16 Every Edge Is a Bridge

Prove that if every edge of a connected graph is a bridge, then the graph is a tree.

Q17 Characterizing Bridges by Cycles

Prove that an edge of a graph is a bridge if and only if it does not belong to any cycle.

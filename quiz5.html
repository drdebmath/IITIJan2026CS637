Filtered West Questions Covered in the Lectures

Chapter 1: Fundamental Concepts
  1. Define a simple graph. What distinguishes it from a multigraph and a pseudograph?
  2. Let \(G\) be a graph with vertex set \(V = \{1, 2, 3, 4, 5\}\) and edge set \(E = \{12, 13, 24, 35, 45\}\). Draw \(G\), write its adjacency matrix, and determine whether \(G\) is bipartite.
  3. The Petersen graph has 10 vertices and 15 edges. Verify that it is 3-regular and has girth 5.
  4. Define the complete bipartite graph \(K_{m,n}\). How many edges does \(K_{m,n}\) have? For which values of \(m, n\) is \(K_{m,n}\) a regular graph?
  5. Prove that \(K_n\) has \(\binom{n}{2}\) edges and is \((n-1)\)-regular.
  6. A graph \(G\) has adjacency matrix \(A\). What does the \((i,j)\)-entry of \(A^2\) count? Prove your answer.
  7. Prove that every closed odd walk in a graph contains an odd cycle.
  8. Let \(G\) be a graph. Prove that \(G\) is bipartite if and only if it contains no odd cycle.
  9. Show that in any graph \(G\), the number of vertices of odd degree is even.
  10. State and prove the Handshaking Lemma:
    \[ \sum_{v \in V(G)} d(v) = 2|E(G)|. \]
  11. A sequence \((d_1, d_2, \ldots, d_n)\) of non-negative integers is graphic if it is the degree sequence of some simple graph. Use the Erdős-Gallai theorem to determine whether \((5, 4, 3, 3, 2, 2, 1)\) is graphic.
  12. A \(k\)-regular bipartite graph with parts \(X\) and \(Y\) satisfies \(|X| = |Y|\). Prove this using degree counting.
Chapter 3: Matchings and Factors
  1. State and prove Hall's Marriage Theorem: a bipartite graph \(G\) with parts \(X\) and \(Y\) has a matching that saturates \(X\) if and only if \(|N(S)| \geq |S|\) for every \(S \subseteq X\).
  2. Define a maximum matching, a perfect matching, and a maximal matching. Give an example showing that a maximal matching need not be maximum.
  3. Prove that every \(k\)-regular bipartite graph, where \(k \geq 1\), has a perfect matching, using Hall's theorem.

Additional Course-Based Practice

Questions 16-35 Based on the Course Graph Theory Lectures
  1. Define each of the following terms: graph, path, cycle, clique, bipartite graph, cut vertex, and bridge.
  2. Let \(G\) have vertex set \(V=\{v_1,v_2,v_3,v_4\}\) and edge set
    \[ E=\{v_1v_2,\; v_1v_3,\; v_2v_4,\; v_3v_4\}. \]
    Write the adjacency matrix and the degree of each vertex.
  3. For the same graph as in Question 17, write one possible incidence matrix. State clearly the order of the vertices and edges that you use.
  4. Prove that a graph is bipartite if and only if it has no odd cycle.
  5. Prove the handshaking lemma
    \[ \sum_{v\in V(G)} \deg(v) = 2|E(G)|. \]
    Deduce that the number of odd-degree vertices in a graph is even.
  6. Prove that every tree on \(n\) vertices has exactly \(n-1\) edges. Then prove the converse: every connected graph on \(n\) vertices with \(n-1\) edges is a tree.
  7. State two immediate necessary conditions for a nonnegative integer sequence
    \[ d_1 \ge d_2 \ge \cdots \ge d_n \]
    to be graphical. Give one example of a sequence satisfying these necessary conditions but still not graphical.
  8. Use the Havel-Hakimi process to determine whether the sequence
    \[ (4,3,3,2,2,2) \]
    is graphical. If it is graphical, construct one realizing graph.
  9. Let \(A\) be the adjacency matrix of a simple undirected graph \(G\) with eigenvalues \(\lambda_1,\dots,\lambda_n\). Prove that
    \[ \sum_{i=1}^n \lambda_i = 0 \qquad \text{and} \qquad \sum_{i=1}^n \lambda_i^2 = 2|E(G)|. \]
  10. State the meaning of the \((i,j)\)-entry of \(A^k\). Then explain how this fact can be used to test whether there is a walk of length \(k\) from \(v_i\) to \(v_j\).
  11. Prove that the path graph \(P_n\) with \(n \ge 2\) has exactly two non-cut vertices.
  12. Prove that a connected graph with \(n\) vertices and \(n\) edges has exactly one cycle.
  13. Let \(T\) be a tree with \(n\) vertices. Suppose \(T\) has \(n-k+1\) leaves and exactly one vertex of each degree \(2,3,\dots,k\). Find the relation between \(n\) and \(k\).
  14. Prove by induction that every finite connected simple graph in which each vertex has degree \(2\) is a cycle.
  15. Prove the same statement as in Question 29 by contradiction using a minimal counterexample and suppression of a degree-\(2\) vertex.
  16. State Dirac's theorem. Then prove it using a maximum non-Hamiltonian graph. Your proof should explain clearly why the contradiction arises.
  17. For each of the following values of \(n\), determine the minimum degree threshold given by Dirac's theorem and explain what conclusion it gives about Hamiltonicity:
    \[ n=6,\qquad n=7,\qquad n=10. \]
  18. Define matching, maximal matching, maximum matching, perfect matching, saturated vertex, and unsaturated vertex. Then explain why every maximum matching is maximal, but not every maximal matching is maximum.
  19. Consider the bipartite graph \(G=(X \cup Y,E)\), where
    \[ X=\{x_1,x_2,x_3,x_4\}, \qquad Y=\{y_1,y_2,y_3,y_4,y_5\}, \] \[ N(x_1)=\{y_1,y_2\},\quad N(x_2)=\{y_2,y_3\},\quad N(x_3)=\{y_3,y_4\},\quad N(x_4)=\{y_1,y_4,y_5\}. \]
    Check Hall's condition for subsets of \(X\), and determine whether there exists a matching saturating all vertices of \(X\).
  20. State Hall's Marriage Theorem and prove both directions:
    • Show that Hall's condition is necessary.
    • Show that Hall's condition is sufficient using induction on \(|X|\).
